# BloxPulse فارسی — نسخه اصلاح‌شده

## نصب روی FadeHost
1. فایل‌های این بسته را جایگزین فایل‌های قبلی کن.
2. متغیر BOT_TOKEN را در Environment Variables هاست تنظیم کن؛ توکن واقعی را در GitHub نگذار.
3. ADMIN_IDS را با آیدی عددی ادمین‌ها تنظیم کن.
4. اجرا: `python bot.py` و نصب وابستگی‌ها: `pip install -r requirements.txt`.

## مهم
- فایل data.json فعلی را نگه دار؛ آن شامل اطلاعات اعضاست.
- منابع ثالث ممکن است تغییر کنند یا دسترسی را مسدود کنند؛ در آن صورت لاگ خطا را بررسی کن.
- تأیید شماره یعنی کاربر contact خودش را از تلگرام ارسال کرده؛ این تأیید پیامکی نیست.
- دستورهای /members و /status فقط برای ADMIN_IDS هستند.
