# BloxPulse — نسخه کامل (استاک + ولیو کامل + مینی‌اپ)

## قابلیت‌ها
- **استاک زنده** Normal + Mirage از API رسمی
- **ولیو کامل** حدود ۹۰ آیتم (seed + به‌روزرسانی زنده)
- نمایش متنی با زمان
- دکمه مینی‌اپ تلگرام → https://scriptx.ir/BloxTrading/
- سازگار با Python 3.11 و 3.12

## نصب FadeHost
1. فایل‌ها را جایگزین کن
2. Environment:
   - BOT_TOKEN
   - ADMIN_IDS
   - MINI_APP_URL=https://scriptx.ir/BloxTrading/  (اختیاری)
3. pip install -r requirements.txt
4. python bot.py

## مهم
- فقط یک نمونه polling
- توکن افشاشده را باطل کن
- data.json را نگه دار
