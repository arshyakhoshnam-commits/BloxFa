# بات روبیکا BloxPulse

## ساخت ربات
1. در روبیکا به @BotFather برو و ربات بساز.
2. توکن را کپی کن.

## اجرا روی FadeHost (رایگان)
- هر اکانت FadeHost **یک** اپ رایگان دارد (256MB، always-on).
- اگر تلگرام روی همان اکانت است، برای روبیکا:
  - یا پلن Starter (~۲ دلار) برای اپ دوم،
  - یا اکانت جدا با ایمیل دیگر برای اپ رایگان دوم،
  - یا هر دو را در یک پروسه اجرا کن (پیشرفته).

متغیر محیطی:
```
RUBIKA_TOKEN=توکن_روبیکا
```

اجرا:
```
pip install -r requirements.txt
python rubika_bot.py
```

## اتصال به تلگرام
هر دو از `core.py` و `values_seed.json` مشترک استفاده می‌کنند.
استاک و ولیو یکسان است.

## دستورات روبیکا
- /start
- استاک یا /stock
- ولیو یا /values
