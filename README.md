# BloxPulse فارسی 🇮🇷

بات فارسی تلگرام برای بررسی استاک و تغییرات ولیوی Blox Fruits، مناسب استقرار روی FadeHost یا هر هاست پایتون.

## قابلیت‌ها
- منوی فارسی با `/start`
- درخواست اشتراک‌گذاری شماره خود کاربر از طریق دکمه تلگرام
- اعلان خصوصی فقط برای کاربرانی که بات را Start کرده‌اند و شماره خودشان را تأیید کرده‌اند
- شناسایی گروه/سوپرگروه‌هایی که بات به آن‌ها اضافه می‌شود
- بررسی دوره‌ای استاک و ولیوها (پیش‌فرض هر ۱ ساعت)
- ارسال اعلان فقط وقتی داده‌ی دریافت‌شده تغییر کند
- نگهداری وضعیت در فایل JSON
- دستورات مدیریتی `/id`، `/status` و `/broadcast متن`

## راه‌اندازی سریع
1. این پوشه را در یک مخزن GitHub آپلود کن.
2. در FadeHost از **Host a bot or app** مخزن را انتخاب کن.
3. Runtime را Python 3.12 قرار بده؛ دستور اجرا: `python bot.py`.
4. متغیر محیطی `BOT_TOKEN` را با توکن BotFather تنظیم کن. توکن را داخل GitHub نگذار.
5. یک بار بات را اجرا کن، در تلگرام `/start` بزن و سپس `/id` را برای دریافت شناسه عددی خودت اجرا کن.
6. شناسه را در متغیر `ADMIN_IDS` بگذار و برنامه را Restart کن.
7. بات را به گروه‌ها و کانال‌ها اضافه کن. برای کانال باید مدیر باشد و مجوز Post Messages داشته باشد. برای گروه‌ها مجوز ارسال پیام لازم است.

## منبع داده و دقت
- استاک از صفحه عمومی `fruityblox.com/stock` خوانده می‌شود.
- ولیوها از صفحه عمومی `bloxfruitsvalues.net/values` خوانده می‌شوند.
- این سایت‌ها رسمیِ Roblox نیستند و ولیوهای ترید، تخمینی و جامعه‌محور هستند. «دقیق و رسمی» بودن برای قیمت ترید تضمین‌پذیر نیست.
- صفحات ممکن است تغییر کنند یا محتوایشان با JavaScript ساخته شود. اگر parser نتواند داده کافی بخواند، ارسال تغییرات را متوقف می‌کند و خطا را در Logs می‌نویسد؛ داده ناقص را به‌عنوان ولیوی جدید منتشر نمی‌کند.
- استاک بازی معمولاً بر اساس چرخه‌های بازی تغییر می‌کند؛ این بات هر ساعت بررسی می‌کند، اما اگر تغییر بین دو بررسی رخ دهد، اعلان در بررسی بعدی ارسال می‌شود.
- اجرای اولیه فقط داده پایه را ذخیره می‌کند و اعلان انبوه نمی‌فرستد. پس از آن، تغییرات شناسایی‌شده منتشر می‌شوند.

## تأیید شماره
این نسخه شماره را با قابلیت `request_contact` تلگرام می‌گیرد و بررسی می‌کند که `contact.user_id` با شناسه همان کاربر یکی باشد. این روش کد SMS جداگانه ارسال نمی‌کند و شماره کاربر باید توسط خود او به اشتراک گذاشته شود.

## پایداری
برای نگهداری پایدار `data/data.json`، از دیسک دائمی/Volume هاست استفاده کن. اگر فایل‌سیستم هاست موقتی باشد، وضعیت کاربران و آخرین مقادیر پس از Deploy ممکن است پاک شود. برای استفاده بزرگ، SQLite یا PostgreSQL توصیه می‌شود.

## دستورات
- `/start` — منو و ثبت‌نام
- `/id` — شناسه تلگرام خودت
- `/status` — آمار (فقط مدیر)
- `/broadcast متن` — پیام همگانی (فقط مدیر)

## حریم خصوصی
شماره تلفن در فایل داده ذخیره می‌شود؛ دسترسی به فایل را محدود کن و فایل داده را به GitHub آپلود نکن. اگر ذخیره شماره برایت لازم نیست، می‌توانیم نسخه‌ای بسازیم که فقط تأیید تماس را ثبت کند و خود شماره را نگه ندارد.
